# SkillHub Lite 🚀

SkillHub Lite is an Android application developed using **Java** and **XML** in **Android Studio**. The app helps students assess their skills, explore career roadmaps, discover trending technologies, and manage their profile in a simple and user-friendly interface.

## ✨ Features

* 🔐 Login Screen
* 📚 Skill Assessment
* 🗺 Career Roadmaps
* 🔥 Trending Skills
* 👤 User Profile
* 🌙 Modern Dark Theme UI

## 🛠 Tech Stack

* Java
* XML
* Android Studio
* Android SDK

## 📱 APK Download

Download and install the APK to test the application:

**APK File:** `apk/SkillHubLite.apk`
